# ⚡ RuClear

**Быстрый, прозрачный и безопасный оптимизатор для Windows 10 и 11.**

RuClear — это открытый скрипт для комплексной очистки и ускорения системы. Никаких скрытых угроз, вирусов и «окирпиченной» ОС. Вы видите каждую строчку кода и понимаете, за что она отвечает.

### 🔥 Главные возможности:
* **Максимальный буст:** Снижение задержек (input lag), настройка прерываний (MSI-Latency) и отключение парковки ядер.
* **Антишпион:** Блокировка телеметрии Microsoft, поиска Bing и фоновой слежки.
* **Глубокая очистка:** Удаление системного мусора, дампов и кэша драйверов (AMD/NVIDIA).
* **Turbo-Core:** Экстремальный игровой профиль. Закрывает все фоновые процессы и службы для максимального FPS.
* **Super-Purge:** Вырезание встроенного мусора Windows (OneDrive, Xbox Game Bar, Кортана).

**Автор:** проект EGKR (Музыка, Литература, Код).
